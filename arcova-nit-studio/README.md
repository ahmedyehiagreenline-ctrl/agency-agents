# Arcova NIT Studio — صفحة الهبوط للحملات

صفحة واحدة سريعة (HTML + CSS + JS بدون أي مكتبات) معمولة للإعلانات:
حاسبة تكلفة، معرض شغل، مبدأ التسعير، ونموذج حجز معاينة بيسجّل في Google Sheet.

```
arcova-nit-studio/
├── index.html            ← الصفحة
├── config.js             ← كل الإعدادات: الأسعار، الواتساب، رابط الشيت، البيكسل، الصور
├── assets/style.css
├── assets/app.js
├── apps-script/Code.gs   ← كود Google Apps Script اللي بيستقبل الطلبات
└── images/
    ├── work/             ← حط صور شغلك هنا
    └── placeholder/      ← صور توضيحية مؤقتة (امسحها بعد ما تحط صورك)
```

---

## 1) ربط Google Sheet (مرة واحدة)

1. افتح الشيت بتاعك (`1Hax_I25EqB1…`) ← **Extensions → Apps Script**.
2. امسح الكود القديم والصق محتوى `apps-script/Code.gs` كله، واعمل **Save**.
3. من القائمة فوق اختار الدالة `setup` واضغط **Run** (هيطلب صلاحيات، وافق عليها).
   ده بيعمل العناوين، وقائمة الحالة (جديد / تم التواصل / معاينة محجوزة …)، وفولدر صور المواقع على Drive، وتاب **Prices** للأسعار.
4. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. انسخ الرابط اللي آخره `/exec` وحطه في `config.js`:
   ```js
   sheetWebhookUrl: 'https://script.google.com/macros/s/XXXX/exec',
   ```
6. لو عدّلت الكود بعد كده: **Deploy → Manage deployments → Edit → Version: New version**. لو عملت deployment جديد الرابط هيتغير.

> لو الرابط فاضي أو الشيت واقع، الصفحة بتحوّل العميل لواتساب ومعاه كل التفاصيل، عشان مفيش ولا عميل يضيع.

### تغيير الأسعار من الشيت
بعد الربط، الصفحة بتقرا الأسعار من تاب **Prices**. غيّر الرقم في الخانة وخلاص، والصفحة بتتحدث خلال 5 دقايق
(أو شغّل الدالة `refreshPrices` عشان التغيير يظهر فوراً).
- **سعر المتر من / إلى**: نطاق سعر المتر المربع لكل نوع برجولة (توريد + تركيب).
- **أقل قيمة مشروع**: لو المساحة صغيرة، التقدير مش هيقل عن الرقم ده.
- **معامل الخامة**: 1 = السعر الأساسي، 1.2 = أغلى بـ 20% (مثلاً بيتش باين أو قطاع 10×10).
- **سعر ثابت / سعر للمتر**: للإضافات. لو سبتهم فاضيين الإضافة بتظهر "حسب الاختيار".
- **متغيّرش عمود id**، ولو خانة فاضية الصفحة بتستخدم الرقم اللي في `config.js`.

**تنبيه على الإيميل:** اكتب إيميلك في `NOTIFY_EMAIL` جوه `Code.gs` عشان يوصلك إيميل مع كل طلب جديد.

### الأعمدة في الشيت
أول 14 عمود زي النسخة القديمة بالظبط (التاريخ، الاسم، الموبايل، المنطقة، المشروع، المقاس، التقدير، الإضافات، صورة المكان، ملاحظات، المصدر، الحملة، الحالة، متابعة)،
وبعدهم أعمدة جديدة: رقم الطلب، درجة التشطيب، وقت التواصل، utm_medium، utm_content، utm_term، Click ID، صفحة الدخول، Referrer، ولينك واتساب مباشر للعميل.

## 2) إعدادات لازم تراجعها قبل الإعلانات (`config.js`)

| البند | ليه مهم |
|---|---|
| `catalog` | الخدمات وأنواع البرجولات والخامات. **الأسعار الحالية مبدئية**، والأسهل تغيّرها من تاب Prices |
| `addOnGroups` | الإضافات. اللي من غير سعر بيظهر "حسب الاختيار" |
| `brand.logo` | مسار ملف اللوجو، مثلاً `images/logo.png` |
| `stats` | أرقامك الحقيقية (سنين الخبرة، عدد المشاريع، مدة الضمان). الفاضي مش بيظهر |
| `gallery` | صور شغلك (تحت) |
| `testimonials` | آراء عملاء حقيقية فقط. القسم مخفي طول ما هو فاضي |
| `tracking` | أكواد Meta Pixel و GA4 و Google Ads و TikTok |

وفي `index.html` راجع: نظام الدفع (50 / 40 / 10)، مدد التنفيذ في الأسئلة، ووعد "خلال 24 ساعة". دي افتراضات، عدّلها لو مختلفة عندكم.

## 3) إضافة صور الشغل

1. صغّر الصور لعرض 1600px تقريباً (أي أداة زي squoosh.app)، JPG، أقل من 400KB للصورة.
2. حطها في `images/work/` بأسماء إنجليزي من غير مسافات، مثلاً `wood-pergola-zayed-01.jpg`.
3. ضيفها في `config.js`:
   ```js
   { src: 'images/work/wood-pergola-zayed-01.jpg', cat: 'wood', title: 'برجولة خشب موسكي 5×4 م', place: 'الشيخ زايد' },
   ```
   التصنيفات: `wood` خشب · `metal` حديد · `alu` برجولات ألومنيوم · `glass` زجاج · `aluminum` أعمال ألومنيوم · `finishing` تشطيبات · `cladding` كلادينج.
   أول صورة بتظهر كبيرة، فحط أحلى صورة الأول. الفلاتر بتظهر لوحدها لما يبقى فيه صور من أكتر من تصنيف.
4. لو الصورة تصميم 3D ومش مشروع منفّذ، ضيف `kind: 'render'` وهيظهر عليها "تصميم 3D".
   ده مهم في الإعلانات: العميل بيثق أكتر لما الكلام يكون دقيق، وسياسات الإعلانات بتمنع عرض حاجة بشكل مضلل.

## 4) النشر (مجاناً)

أسهل طريق: **Netlify Drop**. افتح app.netlify.com/drop واسحب فولدر `arcova-nit-studio` كله. هتاخد رابط فوراً، وتقدر تربطه بدومين زي `arcova-nit.com`.
بدائل: Cloudflare Pages أو Vercel أو GitHub Pages.

## 5) الحملات الإعلانية

### روابط الحملات (UTM)
كل إعلان لازم يكون ليه رابط بيقول جاي منين. الصفحة بتسجل ده في الشيت تلقائياً:
```
https://YOUR-DOMAIN/?utm_source=facebook&utm_medium=paid&utm_campaign=pergola_oct&utm_content=video_1
https://YOUR-DOMAIN/?utm_source=google&utm_medium=cpc&utm_campaign=glass_rooms&utm_term={keyword}
```
في Meta ممكن تحط في **URL parameters**:
`utm_source=facebook&utm_medium=paid&utm_campaign={{campaign.name}}&utm_content={{ad.name}}`

### الأحداث اللي الصفحة بتبعتها للبيكسل
| الحدث | امتى |
|---|---|
| `PageView` | فتح الصفحة |
| `ViewContent` | أول ما العميل يستخدم الحاسبة أو يفتح صورة |
| `Contact` | ضغط واتساب أو رقم التليفون |
| `Lead` (+ القيمة التقديرية بالجنيه) | إرسال طلب المعاينة. **ده هدف التحسين في الحملة** |

### استغلال شيت العملاء القديم
1. انسخ شيت العملاء كتاب جديد (tab) في نفس ملف الشيت واسمه `Customers`.
2. في Apps Script شغّل الدالة `buildAdsAudience`.
   هتعمل tab اسمه `Ads_Audience` فيه الأرقام بصيغة +20، من غير تكرار، والأسماء والمدينة.
3. نزّله **File → Download → CSV** وارفعه على:
   - **Meta Ads Manager → Audiences → Create → Custom Audience → Customer list**
   - **Google Ads → Tools → Audience manager → Customer list**
4. من الـ Custom Audience اعمل:
   - **Lookalike 1% مصر**: ناس شبه عملائك. ده أقوى جمهور للحملات الباردة.
   - **Exclusion**: استبعد العملاء الحاليين من إعلانات الجذب (أو اعمللهم حملة لوحدهم: صيانة، إضافة موتور، غرفة زجاج).
   - **Re-engagement**: رسالة للعملاء القدام (عرض خاص أو "رشّحنا لصاحبك").

> ارفع بس بيانات عملاء اتعاملوا معاك فعلاً، وخلي عندك سياسة خصوصية واضحة. Meta بتشفّر البيانات قبل المطابقة.

### هيكل حملة مقترح للبداية
| الحملة | الجمهور | الإعلان | الهدف |
|---|---|---|---|
| جذب — برجولات | Lookalike 1% + اهتمامات (Home improvement, Gardening, Real estate) في التجمع / زايد / أكتوبر / الساحل | فيديو قبل/بعد 15 ثانية | Leads (Pixel: Lead) |
| جذب — زجاج وألومنيوم | نفس الجمهور، أعمار 30–60 | صور مشاريع Carousel | Leads |
| ريتارجتنج | زوّار الصفحة آخر 30 يوم اللي ما عملوش Lead | "احسب تكلفة مشروعك في دقيقة" | Leads |
| عملاء قدام | Custom Audience من الشيت | عرض إضافات / ترشيح | Messages (واتساب) |

ابدأ بميزانية صغيرة لكل مجموعة لمدة 5–7 أيام، وقارن تكلفة الـ Lead من عمود المصدر والحملة في الشيت، وبعدين زوّد على الأحسن.
